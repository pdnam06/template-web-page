Web Technology

HTML stands for HyperText Markup Language. It is used to design web pages using a markup language. HTML is the combination of Hypertext and Markup language. Hypertext defines the link between web pages. A markup language is used to define the text document within tags which define the structure of web pages. HTML is used by browsers to display text, images and other content.

C Programming

C is a procedural programming language. It was developed by Dennis Ritchie as a system programming language. The main features of C include low-level access to memory, a simple set of keywords and a clean programming style.

Java

Java has been one of the most popular programming languages for many years. Java is Object Oriented. Java code is compiled into bytecode. The bytecode is executed on the Java Virtual Machine (JVM), allowing Java applications to run on different operating systems.
